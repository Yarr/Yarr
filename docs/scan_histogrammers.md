# Scan Data Histogrammers

## DataArchiver

Write data to disk

## HitsPerEvent

Build a histogram of the number hits for each event.

## L13d

Build a 3D histogram of hits in events with the same trigger number.

## L1Dist

Build a histogram of trigger separation. This histograms the delta
between two BCIDs.

## L1Hist

Histogram of raw L0ID as recorded in the FrontEnd event.

In order to adjust for different FrontEnd types, the modulo divisor is
given in the scan configuration.

## BcHist

Histogram of raw BCID as recorded in the FrontEnd event.

In order to adjust for different FrontEnd types, the modulo divisor is
given in the scan configuration.

## OccupancyMap

This builds the standard occupancy histogram.

## TagDist

Build a histogram of the distribution of hits L0tags.

## TagMap

Build a histogram of the average L0tag for each FrontEnd channel.

## Tot2Map

Build a map of ToT squared.

## Tot3d

Build a ToT 3d histogram.

## TotDist

Build a ToT distribution histogram.

## TotMap

Build a ToT map.
